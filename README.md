# 粉刷匠大作战

> 把战场刷成你的颜色。

《粉刷匠大作战》是一个以**涂色占地、区域争夺和轻竞技对战**为核心方向的游戏开发项目。玩家化身粉刷匠，在有限时间内穿梭地图、挥洒颜料、争夺地盘，让自己的颜色覆盖更多区域。

## 项目状态

当前仓库处于**项目初始化与玩法规划阶段**，已建立项目介绍与设计文档。下文描述的是本项目拟实现的游戏方向，不代表已有功能；本仓库暂未上传可运行客户端、服务端或美术资源。

## 游戏介绍

用移动和涂色建立优势，用路线选择与时机判断改变战局。玩家既可以优先占领空白区域，也可以覆盖对手的颜色，围绕关键通道与高价值区域展开争夺。

本项目希望提供规则直观、节奏明快、画面鲜明的轻竞技体验：新玩家能快速理解目标，熟练玩家能通过走位、资源管理和团队配合获得更深的策略空间。

## 核心玩法方向

| 系统 | 设计方向 | 状态 |
| --- | --- | --- |
| 移动与操作 | 简单直观的移动、瞄准与涂色反馈 | 规划中 |
| 颜料覆盖 | 地面按区域记录颜色，支持覆盖与占领统计 | 规划中 |
| 对局目标 | 限时争夺地盘，以最终有效涂色占比判定胜负 | 规划中 |
| 颜料管理 | 通过颜料消耗与补充形成进攻、撤退与恢复的节奏 | 规划中 |
| 地图设计 | 结合障碍、通道和争夺点形成不同路线选择 | 规划中 |
| 模式扩展 | 从单机原型逐步评估个人竞技与团队对抗 | 待评估 |

具体规则、数值和模式以原型验证后的设计为准，详见 [玩法设计](docs/GAME_DESIGN.md)。

## 视觉与体验方向

- **鲜明色彩**：用清晰的阵营色呈现涂色结果与地盘归属。
- **轻松角色**：围绕粉刷匠、画笔、滚筒和颜料构建角色与道具语言。
- **即时反馈**：涂色、覆盖、资源变化与结算都应容易辨认。
- **清晰界面**：对局中优先展示剩余时间、占领比例和颜料状态。

## 开发路线

1. **基础原型**：验证移动、地图、涂色与覆盖效果。
2. **完整单局**：加入倒计时、占领统计、胜负判定与重开流程。
3. **体验打磨**：完善颜料管理、地图路线、操作手感与视听反馈。
4. **对抗扩展**：评估 AI 对手、团队模式和联网方案。
5. **工程完善**：依据最终技术方案补充运行说明、测试、资源规范与发布流程。

以上均为计划，不构成已完成功能列表。
