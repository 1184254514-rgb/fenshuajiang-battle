# 粉刷匠大作战 · 爱好者复刻

> 找回记忆中的圈地与对战乐趣。

这是由游戏爱好者发起的《粉刷匠大作战》**非官方复刻项目**。原游戏已下架，本项目以学习、交流和玩法复现为目的，使用 Godot 与 Lua 适配层重建本地运行环境，并逐步完善游戏体验。

工程包含从原包提取的 Lua 脚本、配置与资源，以及为其编写的 Godot/Lua 适配代码。本项目与原开发商、发行商和运营方无隶属关系，不代表官方复服，也不表示已完全还原原版。

## 下载完整工程与游戏

请到 [版本下载页](https://github.com/1184254514-rgb/fenshuajiang-battle/releases/tag/v0.1.0-lan) 下载：

- **Windows 运行包**：`fenshuajiang-battle-windows-lan.zip`，解压后运行 EXE，无需安装 Godot。
- **完整源码工程**：`fenshuajiang-battle-source.zip`，包含 2862 个工程与资源文件。

游戏和工程以 Releases 附件形式保存。GitHub 自动生成的 `Source code (zip/tar.gz)` 仅是仓库页面内容快照，完整游戏源码请下载上述明确命名的源码包。

## 当前版本

源码压缩包包含可编辑的 Godot 工程、游戏资源、Lua 逻辑、适配层和回归测试；现有版本支持离线限时赛与局域网联机。

- **4 分钟限时圈地**：每局最多 10 名角色，空位由 AI 补齐。
- **轨迹与领地**：不同角色使用不同颜色；撞到自己的旧线时回退到交叉点。
- **技能配置**：选择 1 个主动技能和最多 3 个不同的被动技能；当前接入 7 个主动、8 个被动技能。
- **死亡与结算**：死亡 3 秒后重生，时间结束统一排名，可再次开局。
- **局域网房间**：创建房间、输入房主 IP 加入、房主开局；客机离开由 AI 接管，房主退出则返回大厅。

玩法与还原边界详见 [限时赛说明](限时赛说明.md) 和 [局域网联机说明](局域网联机说明.md)。

## 如何运行源码

本地工程使用 Godot **4.7.2**，渲染模式为 GL Compatibility，包含 lua-gdextension 运行依赖。

1. 从上方版本下载页获取 `fenshuajiang-battle-source.zip` 并解压。
2. 使用 Godot 导入解压后工程根目录的 `project.godot`。
3. 等待首次资源导入完成，运行主场景。

也可以使用命令行（将 `godot` 替换为本机 Godot 可执行文件路径）：

```powershell
godot --editor --path .
godot --path .
```

工程已带有 Windows x86_64 与 Android Lua 扩展库；其他平台需自行准备对应扩展。缓存目录 `.godot/` 不纳入版本控制，将由编辑器生成。

## 如何游玩

- 移动：方向键 / WASD。
- 主动技能：Q / 空格 / 界面技能按钮。
- 离线：在大厅配置技能后，选择「自嗨」进入本地比赛。
- 联机：在同一局域网中，由一人创建房间，其余玩家输入房主的局域网 IP 加入。

局域网使用 **UDP 27866**。无需账号注册或密码；昵称只用于本地房间与对局显示。目前不提供公网匹配、账号数据库、房主迁移或比赛中途加入。

## 源码包工程结构

```text
project.godot            Godot 工程入口
scenes/                 主场景
scripts/                Godot 宿主、渲染、输入与联机界面
lua/ShellClientLua/     原客户端 Lua 脚本
lua/ShellCommonLua/     原公共 Lua 脚本
lua/natives/            引擎接口适配、本地比赛与局域网逻辑
lua/tests/              Lua 回归测试
data/                   原配置与数据
assets/                 图像、模型、音乐与特效资源
fonts/                  字体
addons/                 Lua 扩展及局域网导出插件
tests/                  Godot 场景与流程测试
docs/                   项目说明
```

源码包内含 `NATIVES.md`（架构约定）与 `继续开发记录.md`（历史开发记录）。

## 导出 Windows 版本

在 Godot 中安装对应版本的导出模板，使用已有的 **Windows LAN** 导出预设。保持 `addons/lan_export` 插件启用，它会补入被 `.gdignore` 隐藏、但运行时仍需读取的 Lua 和数据文件。

发行时需将 EXE、PCK 和 Lua 扩展 DLL 放在同一目录。发行包独立于源码管理。
