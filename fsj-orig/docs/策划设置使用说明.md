# 策划设置

## Godot 编辑器

本机可双击桌面“粉刷匠-策划编辑器”快捷方式；或用 Godot 打开本工程的 `project.godot`。右侧停靠栏选择 **策划设置**。插件已在项目中启用；若当前编辑器尚未载入，可重新打开项目，或到“项目 → 项目设置 → 插件”启用“粉刷匠策划设置”。

1. 手动调整参数，或选择“标准4分钟 / 快速测试（60秒）/ 满级技能测试”预设。
2. 点击“保存到项目”。参数写入 `res://data/planner_settings.json`，随源码和后续导出游戏携带。
3. 停止当前运行，点击“运行项目”；运行按钮也会保存当前面板数值。已经运行的比赛不会被编辑器面板中途修改。

| 参数 | 默认 | 范围 |
|---|---:|---:|
| 比赛时长 | 240秒 | 30—3600秒 |
| 重生等待 | 3秒 | 1—30秒 |
| 场上经验刷新目标 | 60份 | 0—300份 |
| 每份经验奖励 | 100 | 1—10000 |
| 开局初始经验 | 0 | 0—9000 |
| 技能冷却比例 | 100% | 0—300%，0表示无冷却 |

预设先填入参数，再保存。满级测试让角色从10级经验开始，技能按原表升到最高6级；不会改写原技能配置表。默认预设保留4分钟和正常冷却。

## 客户端隐藏入口

导出的 Windows 客户端按 **F8** 打开或关闭，**Esc** 关闭。大厅和局内都可打开，正常界面不显示入口按钮。在 Godot 编辑器中主要使用上述停靠栏；编辑器自己的 F8 是停止运行快捷键。

- 左侧参数保存到本机，下一局生效，不改当前局的快照。
- 右侧可立即给本人加1000经验、升满级、清冷却、暂停/恢复AI、重开测试局。
- 联机客人只能查看，保存和调试操作均被禁止；房主重开会通知整间房。
- 参数优先级：项目配置 → 本机覆盖。本机覆盖文件位于 `user://planner-settings.json`；“恢复项目值”会移除本机覆盖。
- Godot 工程、Windows运行包都不包含个人覆盖文件；测试使用单独文件，不污染策划的实际设置。

这是本地策划工具，没有新增网页服务、账号管理或原服后台。比赛仍由既有本地/联机权威逻辑执行。
