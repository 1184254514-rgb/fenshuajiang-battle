# 当前玩法与实现导航

本项目是对已下架《粉刷匠大作战》的爱好者非官方复刻。仓库 Releases 的源码附件现已收录实际 Godot/Lua 工程，早期创建仓库时的通用涂色规划已由本文件替换。

## 当前玩法

现有原型以轨迹圈地为核心。单局 4 分钟，最多 10 名角色；空位由 AI 补齐，死亡 3 秒后重生。支持离线限时赛和同一局域网的房间对局。

具体技能、排名、轨迹回退和复活规则，以根目录 [限时赛说明](../限时赛说明.md) 为准。连接方法、测试范围和网络限制见 [局域网联机说明](../局域网联机说明.md)。

## 主要实现

| 文件 | 职责 |
| --- | --- |
| `scripts/lua_host.gd` | Lua 宿主与 Godot 接口 |
| `scripts/scene_view_3d.gd` | 场景、角色、领地和效果显示 |
| `lua/natives/scene.lua` | 场景与轨迹规则适配 |
| `lua/natives/scene_skills.lua` | 技能行为 |
| `lua/natives/scene_match.lua` | 限时赛、复活与结算 |
| `scripts/lan_session.gd` | ENet 连接、房间与网络会话 |
| `lua/natives/scene_lan.lua` | 房主权威状态与对局同步 |
| `scripts/lan_hud.gd` | 局域网入口和房间界面 |
